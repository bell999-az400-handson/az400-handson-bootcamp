# セキュリティチェック結果

実施日: 2026-05-26

## 修正した問題

| # | 重要度 | 問題 | 対応 |
|---|--------|------|------|
| 1 | **High** | セキュリティヘッダー未設定 (OWASP A05) | `helmet` ミドルウェアを追加。CSP・X-Frame-Options・X-Content-Type-Options 等を自動付与 |
| 2 | **High** | `/info` エンドポイントが内部情報を公開 (OWASP A01) | `nodeVersion`, `platform`, `memory`, `port`, Key Vault URL を削除 |
| 3 | **High** | `/secret` エンドポイントが Key Vault URL を返却 | `vaultUrl` フィールドを削除 |
| 4 | **Medium** | エラーレスポンスが内部エラーメッセージを漏洩 (OWASP A05) | `/secret` と汎用エラーハンドラーの `error.message` を汎用メッセージに置換 |
| 5 | **Medium** | 404 レスポンスにリクエストパスを含める（パス列挙攻撃の補助）| `path: req.path` を削除 |
| 6 | **Medium** | Key Vault Administrator ロールを Web App に付与 (最小権限違反) | `keyVaultAdminRoleAssignment` リソースを削除。必要なのは `Key Vault Secrets User` のみ |
| 7 | **Medium** | `softDeleteRetentionInDays: 7`（最小値で復元猶予が短い）| 7日 → 30日 に変更 |
| 8 | **Critical** | Trivy Action サプライチェーン攻撃 (GHSA-69fq-xp46-6x23) — `0.0.1`〜`0.34.2` の全タグが悪意あるコードに書き換えられた | `@0.35.0` に更新（immutable releases で保護された唯一の安全なバージョン）|

## npm 脆弱性対応（Trivy アラート）

| アラート | 重要度 | ライブラリ | 対応 |
|---------|--------|-----------|------|
| ReDoS via crafted extglob patterns | High | `picomatch` | `overrides` で `^4.0.4` に強制更新 |
| Method injection with POSIX bracket expressions | Medium | `picomatch` | 同上 |
| XSS in Address6 HTML-emitting methods | Medium | `ip-address` | `overrides` で `^10.0.1` に強制更新 |
| DoS via zero step value in brace pattern | Medium | `brace-expansion` | `overrides` で `^5.0.6` に強制更新 |
| DoS via qs.stringify with null/undefined | Medium | `qs` | `overrides` で `^6.15.2` に強制更新 |

## 未修正（要検討）
